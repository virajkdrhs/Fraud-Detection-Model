# Fraud-Detection-Model
Python based, machine learning model to detect fraudulent transactions between accounts.

For the 'AIML Dataset.csv' file, go to [https://www.kaggle.com/datasets/amanalisiddiqui/fraud-detection-dataset?resource=download](url)
download and unzip file in project folder
  Very large file so make sure to allocate storage accordingly

Make sure to run 'setup.ps1' in terminal before running other files to ensure all APIs are downloaded and virtual enviorment(venv) is set up
Terminal Script: powershell -ExecutionPolicy Bypass -File .\setup.ps1

Ensure that Jupyter Notebook file 'analysis_model.ipynb' runs in a python venv kernel.

Followed this tutorial: [https://www.youtube.com/watch?v=4Od5_z28iIE](url)
